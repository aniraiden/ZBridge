# 雕刻图层还原（0.8.0）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 ZBridge 增加"雕刻图层还原"功能（Tool > Layers），导出侧按层导出基准+快照 GoZ，导入侧在 Phase 2 末尾重建图层栈（名/顺序/强度/可见性），版本 0.8.0。

**Architecture:** 沿用单文件 `src/zscript/ZBridge.txt`。导出侧对含图层子工具：全层强度归零导出 `<name>.goz`（基准网格，作为主导入文件）→ 逐层（仅该层强度 1）导出 `Layers/<name>/Layer_<i>.goz` + 写 `Layers/layers.txt`。导入侧 Phase 2 末尾：录制导入快照重建图层（方案 A），全部完成后重跑细分恢复（快照导入会清细分级别）+ 最终强度/可见性 pass。P0 验证失败则转方案 B（MDD + C++ DLL，见附录）。

**Tech Stack:** ZScript（UTF-8 BOM + CRLF，camelCase 无下划线）、GoZ 格式、ZFileUtils（ZFU_RenameCurrentLayer）、官方 `Tool:Layers:*` UI 路径。

**测试模式（用户手测）:** 本项目无自动化测试框架，每个任务的"测试"= 用户在当前 ZBrush 版本运行指定脚本/操作，核对预期结果后反馈。测试脚本位于 `tests/`。
